    絶対王政と啓蒙思想

    プリントNo.11 ／ 教科書p.27〜28

    絶対王政とは

    • 中世ヨーロッパの崩壊（封建制度の崩壊、教皇の衰退）→ 国王による一元的支配（1つにまとまった支配）がすすむ。
    • 絶対王政：国王が絶対的な権力をもっている政治体制（16世紀以降）。
    • 手段：強力な軍隊（＝常備軍）と多くの役人（＝官僚制）。
    • 根拠：王権神授説（王の権力は神から授けられたもの）。
    • つまり議会で話し合って政治を決めるのではない！ → 絶対王政では議会と対立しがち。
    • 重商主義：絶対王政の国王がとった経済政策。特定の商人を保護し、貿易を奨励（輸出を多く）→ 市場と原料供給地を求め、植民地獲得競争へ。

    各国の状況

    国国王ポイント
    イギリス女王エリザベス1世

    軍事力：アメリカ大陸にルイジアナ植民地をひらく
    経済力：フランス東インド会社を再建 → 繁栄しベルサイユ宮殿が建設
    ロシアピョートル1世

    市民革命と啓蒙思想

    • 市民革命：絶対王政を倒し、市民（国民）が中心の自由な社会に変えること。例：イギリス革命（1642〜1688、ピューリタン革命＋名誉革命）、アメリカ独立革命（1776〜1783）、フランス革命（1789〜1799）。
    • 根拠：啓蒙思想（絶対王政を否定し、合理的な社会を目指す考え）。
    人物著書主張影響
    ロック（英）『統治二論』革命権：政府が不公正な場合は革命を起こしてもよいアメリカ独立革命（1776）
    モンテスキュー（仏）『法の精神』三権分立：政府・議会・裁判所に権力をわけるアメリカ合衆国憲法（1787）
    ルソー（仏）『社会契約論』国民主権：国家の主役は国王ではなく国民フランス革命（1789）
    説明問題の型：絶対王政で国王と議会が対立しがちな理由 国王が王権神授説を根拠に絶対的な権力をもち、議会で話し合って政治を決めるのではなかったから。

    イギリス革命

    プリントNo.12 ／ 教科書p.29〜30

    ピューリタン革命（清教徒革命）1642〜1649

    • 中心：イギリスのカルヴァン派（ピューリタン）。地主・商工業者などの「市民階級」→ 自由な経済活動を求める。
    • 背景：重商主義への不満。
    • 1628年 権利の請願：議会が「勝手に税金をかけない・勝手に逮捕しない」ことを王に頼む → 国王チャールズ1世は反発し、議会を閉鎖。
    • 1642年 議会派と国王派で国内の戦いが勃発。
    • 1649年 国王チャールズ1世を議会派の指導者クロムウェルが処刑 → 王政が廃止され共和政に（クロムウェルが政治を担う）。

    名誉革命 1688

    • クロムウェルの死後、チャールズ2世が国王に復帰。
    • Q. なぜ復帰できた？ → 民衆がクロムウェルによる独裁政治に不満をもっていたから。
    • しかしチャールズ2世や、その弟ジェームズ2世は議会を無視。
    • 議会はオランダから新たな国王（メアリとその夫ウィレム）を迎える → ジェームズ2世はフランスへ亡命。血を流さなかったので名誉革命とよぶ。
    • 翌年、新しい王はメアリ2世とウィリアム3世として即位。
    • 1689年「権利の章典」：ウィリアム3世とメアリ2世が議会の権利を法律で認める。
    資料：権利の章典（読み取り問題に注意） ① 国王は議会の承認なしに法律を停止することはできない。
    ④ 国王は議会の承認なしに課税することはできない。
    ⑨ 議会における言論の自由は守られなければならない。
    ⑬ 議会はしばしば開かれなければならない。
    → 意義：イギリス革命の成果をまとめたもの。「王は君臨すれども統治せず」の伝統が誕生 ＝ 立憲君主制の基礎となる。

    アメリカ独立革命

    プリントNo.12 ／ 教科書p.31〜32
    • 17世紀初め、メイフラワー号に乗ったイギリス人がアメリカに移住 → 先住民（ネイティブアメリカン）から土地を奪い、約100年間で植民地を建設（＝アメリカ13植民地）。
    • Q. なぜイギリス人がきた？ → このイギリス人はピューリタンだったから。
    • 1765年 イギリス本国は植民地に自治を認める一方、印紙法（植民地の印刷物に課税）を制定。
    • 植民地側は「代表なくして課税なし」と唱えて抗議（本国の議会に13植民地は参加していないのに、勝手に税金をかけるのはおかしい）。
    • 1773年 ボストン茶会事件：茶税に反発し、イギリス東インド会社の茶をボストン港に投げ捨てる → イギリスはボストン港を閉鎖。
    • 1775年 アメリカ独立戦争開始。総司令官はワシントン。
    • 1776年7月4日 アメリカ独立宣言発表（ジェファソンが起草）。思想家ロックの革命権の影響。
    • 1783年 アメリカがイギリスに勝利。イギリスが独立を承認。
    • 1787年 アメリカ合衆国憲法：三権分立（モンテスキューの影響）、共和政（皇帝や国王などの君主がいない政治）↳ 大統領制を採用。
    • 意義：独立と同時に市民革命を実現。
    資料：アメリカ独立宣言（革命権の部分） 「いかなる政府であってもこの目的をこわすものになったときは、人民は政府を変更もしくは廃止して、…新しい政府を作ることができる。」→ ロックの革命権の影響。

    フランス革命とナポレオン

    プリントNo.13 ／ 教科書p.33〜34

    フランス革命

    • 背景：絶対王政とアメリカ独立戦争の支援による財政難 → 平民へ重税。
    • 3つの身分：聖職者・貴族（＝特権身分）、平民（第3身分）。
    • 1789年 国王ルイ16世が貴族にも課税を検討 → 貴族は反発。三部会を再開（3つの身分の議会、1615年に中断）。
    • 議決方式をめぐり貴族と平民が対立 → 平民は三部会を離脱し国民議会を結成。
    • 1789年6月20日 憲法が制定されるまで国民議会を解散しないと約束 ＝ 球戯場の誓い（テニスコートの誓い）。
    • 1789年7月14日 平民たちがバスチーユ牢獄を襲撃 ＝ フランス革命の開始。
    • 1789年8月 国民議会がフランス人権宣言を発表（聖職者や貴族の特権を廃止）。起草はラファイエット。
    • 1791年 国王一家がオーストリアへの国外逃亡をはかるも失敗・逮捕 → 周辺諸国は革命が広がるのをおそれ、革命に干渉。
    • 1792年 フランスがオーストリアに宣戦布告 → 苦戦 → 義勇軍を結成 → 国民意識が高まる → 王政廃止、共和政が開始。
    • 1793年 1月 ルイ16世処刑、10月 マリー・アントワネットも処刑 → イギリス・オーストリアを中心に同盟を組みフランスを攻撃。政治は不安定に。
    資料：人権宣言（人間および市民の権利の宣言） 第1条 人は、生まれながらにして、自由かつ平等な権利をもっている。
    第3条 あらゆる主権の原理は、本来、国民の中にある。
    第17条 財産の所有権は、神聖で不可侵の権利である。

    ナポレオン

    • 革命の邪魔をするヨーロッパ諸国に対抗。中心はコルシカ島出身の軍人ナポレオン → 外国への遠征で活躍し人気を得る → 不安定だった国内の政権をにぎる。
    • 1804年 ナポレオン法典（フランス民法典）制定。内容：所有権の不可侵、法の下の平等。意義：フランス革命の成果を表す。
    • 1804年 国民投票で皇帝に就任（＝ナポレオン1世）。共和政ではなく帝政へ。
    • 外国遠征をくりかえし、イギリス以外のヨーロッパのほぼ全域を支配 → 自由・平等の考えがヨーロッパに広がる一方、各国でも国民意識が高まる。
    • 1812年 ロシア遠征に大失敗 → 各国が一斉に攻撃、ナポレオンは敗北 → 地中海のエルバ島に流罪。
    • 1814年 混乱収拾のためウィーン会議開催 → 話し合いが長引き、ナポレオンはエルバ島を脱出しパリに戻る。
    • 1815年 ナポレオン再び敗北。南大西洋のセントヘレナ島に流罪。

    産業革命

    プリントNo.14 ／ 教科書p.35〜37
    • 産業革命：手作業ではなく、機械を使って大量生産すること（工場制手工業から工場制機械工業へ変化）。

    なぜイギリスで始まった？

    • 15〜17世紀 大航海時代：ヨーロッパとアジアの直接貿易が始まる → イギリス東インド会社はインドから綿織物を輸入 → 輸入が多く貿易は赤字。
    • （絶対王政のころのイギリスの主な輸出品は毛織物）
    • 18世紀 イギリスは綿織物の国内生産（国産化）を目指す。簡単に安く売るには → 大量に作る → 綿糸を作る紡績機や布を織る織機を発明（軽工業）→ 大量生産が可能に ＝ 産業革命の始まり。

    機械の動力

    • 18世紀前半：人力や水力が中心。
    • 18世紀後半：ワットが蒸気機関を改良 → 水力から蒸気力へ。燃料は石炭。カートライトの力織機は蒸気機関で布を織る。

    産業革命の影響

    • ① 重工業の発展：機械を作るため鉄鋼業が発達 → 鉄鉱石・石炭の採掘もさかんに。
    • ② 輸送手段の発達：フルトンが蒸気船を発明、スティーブンソンが蒸気機関車を改良 → イギリスは「世界の工場」と呼ばれる。
    • ③ 経済の変化：農業社会から工業社会へ。重商主義（特定の商人が活躍）から資本主義（だれでも経済活動できる）の時代へ。平等を目指す社会主義も登場（マルクス（独）が『資本論』を出版）。
    • ④ 労働問題：労働者が増える一方、工場の持ち主である資本家は利潤を求めるため労働環境は劣悪に。長時間労働、低賃金労働、児童労働。
    • 都市の人口が増加 → 水道の不備、トイレの不足、住宅の密集 → 伝染病（コレラ、天然痘）が流行 → 労働条件の改善を求める労働運動。
    • 政府の対策：1833年 イギリスで工場法成立（未成年の夜間労働禁止、13歳未満は9時間労働など）。

    政治参加の広がり（イギリス）

    • 参政権（選挙権）の拡大：以前は貴族のみ → 選挙法改正で多くの人が政治参加。
    • 1832年 第1回選挙法改正：資本家に参政権 → チャーティスト運動（1838〜48）：労働者が政治改革を求める → 1867年 第2回選挙法改正：都市の労働者に参政権。
    • 19世紀 二大政党制：保守党（貴族・地主が支持）と自由党（資本家が支持）。20世紀には労働党も結成。
    • イギリスは原料供給地と市場を求めて海外に進出 → アメリカなどを植民地に。アメリカは砂糖・タバコ・コーヒー・綿花の大農場（プランテーション）に依存し、モノカルチャー経済（特定の農作物の生産・輸出に依存）に。

    19世紀のヨーロッパ

    プリントNo.15 ／ 教科書p.31〜32、37〜38

    フランス

    • ナポレオンの失脚（地位や立場を失うこと）後、ウィーン会議（1814〜15）→ ブルボン家が復活 ＝ 王政の復活。
    • 1830年 七月革命で国王は国外追放。参考：ドラクロワ「民衆を導く自由の女神」→ 自由主義者の国王ルイ＝フィリップが誕生し、産業革命が進む。
    • 1848年 二月革命：労働者らも立ち上がる → ルイ＝フィリップは亡命、再び共和政へ。普通選挙も実現。
    • ルイ＝ナポレオン（ナポレオンの甥）が大統領に当選 → 1852年 ナポレオン3世として即位（在位1852〜70）。

    イタリアとドイツの統一

    • イタリア：中世以来、多くの共和国（都市共和国、教皇領など）に分裂 → サルデーニャ王国が中心となり統一を目指す → 首相カヴールにより統一（＝イタリア王国 1861）。
    • ドイツ：30年戦争（1618〜48）以来、中小の国々に分裂 → プロイセン王国が中心となり統一を目指す（首相ビスマルク）。
    • 課題：オーストリア・フランスがプロイセン中心の統一に反対 → プロイセンが戦争で勝利し統一（＝ドイツ帝国 1871、立憲君主制）。
    • 参考：プロイセン憲法（1851）は大日本帝国憲法（1889）のもとになった。

    ロシア

    • 絶対王政を継続。18世紀：エカチェリーナ2世（在位1762〜96）が農奴制を強化。
    • 南下政策：冬でも凍らない港（＝不凍港）を探すための外交政策。目標は地中海沿岸 → 英仏は反発。
    • 19世紀：クリミア戦争（1853〜56）。ロシアが本格的に地中海へ進出しようとして英仏と対立。ナイチンゲール（英）が従軍看護師として活躍。
    • 結果：ロシアの敗北 → 近代化に着手。農奴解放（1861）→ ロシアでも産業革命が進む。

    19世紀のアメリカ大陸

    プリントNo.15 ／ 教科書p.37〜38

    ラテンアメリカ

    • ヨーロッパの植民地支配から独立を目指す。背景：① アメリカ独立革命・フランス革命の影響　② ナポレオン戦争によるポルトガル・スペインの混乱。
    • クリオーリョ（南米生まれの白人）を中心に独立運動が起きる。

    アメリカ合衆国と南北戦争

    • 独立後、人口が増えフロンティア（西部）を開拓。1848年にはカリフォルニアを獲得 → ゴールドラッシュで西海岸に移住者が殺到。
    • 課題：西部の開拓地をめぐり、北部と南部が対立。
    北部南部
    産業商工業中心 → 保護貿易を主張（英に対抗し、自国製品を売りたい）農業中心 → 自由貿易を主張（英と協調し、綿花を輸出したい）
    奴隷制反対賛成
    支持政党共和党民主党
    • 1861年 南北戦争勃発。きっかけ：共和党のリンカーンが大統領に当選（1860）→ 反発した南部がアメリカ連合国を結成 → 認めない北部と戦争。
    • 当初は南部が有利。
    • 1862年 ホームステッド法制定 → 西部農民が北部を支持。
    • 1863年 奴隷解放宣言 → 国内外が北部を支持。同年 ゲティスバーグの戦いで北部が勝利。演説「人民の、人民による、人民のための政治」（Government of the people, by the people, for the people）。
    • 結果：北部・南部・西部を束ねる巨大国家に。黒人奴隷は解放されたが人種差別は続く（ジム＝クロウ法（人種隔離制度）、KKK（クー・クラックス・クラン））。
    説明問題の型：北部は奴隷制に反対し、南部は賛成したのはなぜか 北部は工業化を進めるため、奴隷ではなく労働者が必要だった。南部はプランテーション（綿花の大農場）のために奴隷が必要だったから。

    ヨーロッパの科学と文化

    プリントNo.16（宿題プリント・考査範囲に含む） ／ 教科書p.39〜40

    物理学レントゲン（独）X線発見［19世紀末］→ 第1回ノーベル物理学賞
    物理学キュリー夫妻（ポーランド）放射性物質ラジウム発見［19世紀末］

    発明モールス（米）電信機を発明

    発明ノーベル（スウェーデン）ダイナマイトを発明 → 鉱山の採掘や戦争などに使用
    • 医学：顕微鏡の発明 → 病原菌の発見 → 伝染病の予防が進む。下水道の整備 → 都市の衛生が改善。

    新しい芸術

    • 文学：18世紀末〜19世紀前半 ロマン主義（人間の感情や想像力を重視）例 ユーゴー（仏）『レ・ミゼラブル』。19世紀後半 自然主義（人間や社会をありのままに描く）例 ドストエフスキー『罪と罰』。
    • 絵画：19世紀末 印象派（色彩が明るい絵）例 モネ（仏）「睡蓮」、ゴッホ（オランダ）「ひまわり」。
    • ゴッホ「タンギー爺さん」、モネ「ラ・ジャポネーズ」には日本の浮世絵が描かれている → 欧米で日本ブーム（ジャポニスム）。ゴッホは歌川広重の「名所江戸百景 亀戸梅屋敷」をまねた絵も描いた。
    説明問題の型：なぜ日本の絵画の影響は18世紀以前ではなく19世紀に表れたのか 以前の日本は鎖国政策で海外との交流が制限されていたが、19世紀半ばに開国したことで海外との交流が盛んになったから。

    ヨーロッパの近世

    実力錬成テキストp.48〜53 を想定
    • ルネサンス（文芸復興）：14世紀にイタリアで始まる。古代ギリシャ・ローマの文化を見直す。レオナルド・ダ・ヴィンチ『モナ・リザ』、ミケランジェロ『ダビデ』。
    • 火薬・羅針盤・活版印刷の改良。活版印刷はグーテンベルク。
    • 宗教改革：1517年、ドイツのルターがローマ教皇の免罪符（贖宥状）販売を批判。スイスではカルバン。新しい宗派＝プロテスタント。
    • カトリック側はイエズス会をつくり海外へ布教（ザビエルが日本へ）。
    • 大航海時代：アジアの香辛料を直接手に入れ、キリスト教を広めるため。コロンブス1492年 西インド諸島、バスコ・ダ・ガマ1498年 インド、マゼランの船隊が世界一周。
    説明問題の型：宗教改革が起こった理由 ローマ教皇が大聖堂の修築費を集めるため免罪符を売り出したことに対し、ルターが「信仰のよりどころは聖書だけ」と批判したから。
