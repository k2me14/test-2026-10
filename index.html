南アジア

自然と気候

  • 北に世界最高峰エベレストのあるヒマラヤ山脈。インドを東に流れるガンジス川、パキスタンを流れるインダス川。インド半島の内陸はデカン高原。
  • 季節風（モンスーン）の影響が大きい。夏はインド洋から南西の湿った風 → 雨季。冬は大陸から北東の乾いた風 → 乾季。

宗教と社会

  • インドはヒンドゥー教が約8割。牛は神聖な動物なので食べない。ガンジス川で沐浴する。
  • ヒンドゥー教と結びついた身分制度カースト。現在は憲法で差別が禁止されているが、結婚や職業に影響が残る。
  • パキスタン・バングラデシュはイスラム教、スリランカは仏教が多い。
  • インドの人口は約14億人。2023年に中国を抜いて世界一になった。

農業

  • 雨が多いガンジス川下流域・バングラデシュ → 稲（米）。雨の少ないガンジス川上流やインダス川流域（パンジャブ地方） → 小麦。
  • デカン高原 → 綿花。インド北東部のアッサム地方やスリランカ → 茶。

工業・産業

  • ICT（情報通信技術）産業が成長。南部のベンガルール（バンガロール）に企業が集まる。
  • 日本などの外国企業が進出し、自動車やオートバイの生産も伸びている。
説明問題の型：インドでICT産業が発達した理由 ① 英語を話せる人が多い　② 数学の教育水準が高く技術者が多い　③ アメリカと昼夜が逆（時差が約半日）なので、アメリカの夜にインドで仕事を引き継げる　④ 技術者の賃金が比較的安い

西アジア・中央アジア

自然と暮らし

  • 大部分が乾燥帯。砂漠が広がり、雨が少ない。
  • 水が得られるオアシスで、なつめやしや小麦をつくる。
  • 草や水を求めて羊・ラクダなどと移動する遊牧。
  • 中央アジアは内陸で、カスピ海がある。昔は東西を結ぶシルクロードが通っていた。

イスラム教

  • 西アジア・中央アジアではイスラム教を信仰する人が多い。アラブの国々ではアラビア語。
  • 聖典はコーラン（クルアーン）。聖地はサウジアラビアのメッカ。
  • 1日5回、メッカの方向に礼拝する。豚肉を食べない・酒を飲まない。
  • ラマダンの月は日の出から日没まで断食する。教えにそった食品はハラール。

石油と経済

  • ペルシア湾の沿岸は世界有数の石油（原油）の産地。サウジアラビア、イラン、イラク、クウェート、アラブ首長国連邦など。
  • 産油国はOPEC（石油輸出国機構）をつくり、生産量や価格に影響を与えている。
  • 日本は輸入する原油の9割以上を西アジア（中東）からタンカーで運んでいる。
  • 石油など特定の産物の輸出にたよる経済＝モノカルチャー経済。
  • アラブ首長国連邦のドバイは、石油にたよらないよう観光や金融、物流に力を入れている。
  • 中央アジアの国々はソ連（ソビエト連邦）の一部だった。石油・天然ガスや、携帯電話などに使われるレアメタルが豊富。
説明問題の型：石油にたよる経済の問題点 石油の価格が変わると国の収入が不安定になる。また石油はいつかなくなる資源なので、観光業や工業などほかの産業を育てる必要がある。

中国

  • 人口は約14億人。約9割が漢民族、ほかに55の少数民族。
  • 人口をおさえるため1979年から一人っ子政策（2015年に廃止）。その結果少子高齢化が急に進んでいる。
  • 北部を黄河、中部を長江が流れる。西部にはチベット高原や砂漠。
  • 農業：北部（降水量少）は畑作で小麦・とうもろこし、南部（温暖・雨多）は稲作、東北は大豆・とうもろこし、西部の乾燥地は牧畜。
  • 外国企業を呼び込むため沿岸部に経済特区（シェンチェンなど）。工業製品を世界に輸出し「世界の工場」に。
  • 沿岸部と内陸部の経済格差 → 内陸部を開発する西部大開発。急速な工業化で大気汚染などの環境問題も。
説明問題の型：沿岸部と内陸部に格差が生まれた理由 経済特区が沿岸部につくられ、外国企業が進出して工業が発達したから。内陸部は農村が多く、収入が低いままだった。

朝鮮半島

  • 南は大韓民国（韓国）、首都ソウル。北は朝鮮民主主義人民共和国（北朝鮮）、首都ピョンヤン。
  • 独自の文字ハングル。年長者を敬う儒教の教えが大切にされてきた。床下暖房のオンドル、キムチなどの食文化。
  • 韓国は1960年代から急速に工業化しアジアNIESの一つに。現在は半導体・電子機器・自動車・造船がさかん。
  • 首都ソウルに人口や産業が集中している。

東南アジア

  • 大部分が熱帯。季節風の影響で雨季と乾季がある。
  • メコン川などの流域で稲作。1年に2回米をつくる二期作も。タイ・ベトナムは米の輸出が多い。
  • 植民地時代に開かれた大農園プランテーション：天然ゴム、油やし（パーム油：マレーシア・インドネシア）、バナナ（フィリピン）、コーヒー（ベトナム）。
  • 宗教：インドネシア・マレーシアはイスラム教、フィリピンはキリスト教、タイは仏教。中国から移り住んだ華人も多い。
  • 1967年にASEAN（東南アジア諸国連合）を結成。2025年に東ティモールが加わり11か国（教科書では10か国と書かれていることもある）。
  • 賃金が安く労働力が豊富なので、日本などの企業が工業団地に工場をつくった。
  • えびの養殖池をつくるためマングローブが切られ、環境問題になっている。熱帯雨林の伐採も問題。
